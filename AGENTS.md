# FuncDraw: FuncScript-based Vector Graphics Authoring Tool

This repo hosts the core framework for FuncDraw.

## Focus areas
- packages/funcdraw-core - core FuncDraw engine
- packages/funcdraw-play - web-based renderer implementation

## Repo layout notes
- funcscript/ - FuncScript repo as a submodule
- examples/ - art projects and supporting libraries; we rely on them to stress-test capabilities and will ship a curated set with releases

## Quick start reading list
- FuncScript references: funcscript/docs/index.md, funcscript/docs/examples.md, funcscript/docs/reference/built-in-symbols.md
- FuncScript developer guides: funcscript/docs/developers/test-framework.md, funcscript/docs/developers/fs-package.md
- FuncDraw manual: docs/funcdraw-manual.md
