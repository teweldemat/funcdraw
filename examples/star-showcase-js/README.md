# Star Showcase (JavaScript) Example

This example mirrors the FuncScript star showcase but defines the scene entirely in JavaScript to exercise the FuncScript ↔︎ JavaScript binding when running through FuncDraw.

## Setup

```bash
cd examples/star-showcase-js
npm install
```

## Run

```bash
npm run play
```

`funcdraw-play` loads `art/scene.js`, evaluates the JavaScript block, and renders the resulting scene.
