# @funcdraw/testlib-js

JavaScript twin of the FuncScript square helper. The package publishes an `art/square.js` file that returns a function producing FuncDraw rectangle primitives centered at a point with a chosen side length.

Install it inside another FuncDraw project and call `package("@funcdraw/testlib-js")` (or grab the function directly via `package("@funcdraw/testlib-js").square`).
